# Play patterns

Choose a pattern from the brief; combine patterns only when they support the same concept.

| Pattern | Useful design prompts |
|---|---|
| Pretend/character | What poses, expressions, accessories, or transformations help enact a story? |
| Build/combine | What can be assembled, reconfigured, connected, or rebuilt? |
| Move/operate | What does pushing, rolling, turning, or winding make happen? How does play restart? |
| Sensory/manipulative | What texture, click, resistance, return, or visible motion rewards an action? |
| Discover/solve | What can be found, aligned, opened, or figured out? Are clues and difficulty appropriate to the concept? |
| Collect/world-build | How do pieces relate to one another and create new scenes or stories? |

Describe an interaction as **invitation → player action → toy response → next possibility**. Open-ended play can have many possible next actions instead of one goal. Prefer a few meaningful interactions over a feature checklist.

Quick concept recipes: a character changes pose to embody a story; a cart reveals a distinctive movement when pushed; a transformable object changes role when reconfigured; a flexure toy gives a visible or tactile return when squeezed. Specify the actual action and response for the chosen brief; these are starting prompts, not required features.
