# Avaliação piloto: criatura articulada

**Pedido:** “Quero um brinquedo articulado imprimível em 3D, uma criatura fantástica que dê vontade de brincar. Proponha um conceito e a arquitetura mecânica.”

| Critério | Baseline: skills atuais | Candidata toy-modeler |
|---|---|---|
| Ação/loop | Draco: criar cena → mudar pose/asas/cauda → testar equilíbrio → inventar outra cena | Nimbo: abrir asas/mudar pose → resposta visível → inventar nova pose/história |
| Juntas com propósito | Cabeça para olhar, asas para abrir, pernas para poses, cauda para equilíbrio | Asas para estados, cabeça/membros para encenar, cauda para silhueta/pose |
| Variação | Cenas e configurações | Poses e histórias |
| Hipótese versus observação | Implícito que precisa prototipar | Declarado explicitamente: nada foi observado fisicamente |
| Artefato estruturado | Resposta narrativa; sem brief reutilizável | Inclui loop, valor lúdico das partes e perguntas de protótipo |

**Resultado:** o baseline já propôs uma experiência forte e não mostrou falha clara de criatividade. A candidata tornou a lógica de interação e o estado de hipótese mais explícitos e fáceis de levar para CAD/prototipagem. Um único teste conceitual não demonstra maior diversão nem melhora física; a avaliação precisa ser repetida com o modelo e, idealmente, com uma impressão observada.
