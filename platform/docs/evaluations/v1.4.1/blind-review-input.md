# Blind comparison material: CAD3D design sessions
Do not infer version identity. For each pair, score each output on ten dimensions (0 absent/contradictory, 1 partial/generic, 2 specific/usable), max 20. Criteria: (1) function/context, (2) need vs requirement/constraint/preference/solution/unknown distinction, (3) distinct concept alternatives before geometry, (4) selection tradeoff rationale, (5) functional system/interfaces before geometry, (6) spatial budget/access/space explanation, (7) components mapped to functions, (8) mechanics, retention/service, (9) risks and evidence vs hypothesis, (10) proportional executable CAD/review. Explain critical failure(s); do not award document volume. Evaluate evidence, not claims. The pairs were run in fresh external project directories with identical prompts under the same Codex CLI/model configuration. Baseline transcript gate facts: in A, custom `src/model.py` was written after the first `architecture validate` returned FAIL; in B, custom model preceded clean validation and the later validation returned WARNING, then build ran; in C, custom model/assembly preceded the first non-exception validation, which returned FAIL, then modeling/build continued. Thus the older skill also failed to enforce its stated pre-CAD gate; do not attribute this behavior as a new regression, but score whether V1.4.1 improves it (it does not: candidate A/B/C likewise modeled after a failing first validation).
