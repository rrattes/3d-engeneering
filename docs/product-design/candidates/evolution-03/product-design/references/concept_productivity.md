# Concept depth and identity across parts

Use after engineering, when the optional design stage is requested. The current
CAD, requirement contract, interfaces and unresolved findings are the reference.

## A compact direction, not a mandatory workshop

Record use context, visible faces, one dominant style/substyle, two or three desired
qualities and concrete geometric consequences. For a chosen direction or simple
part, develop it directly. For an open consequential choice, compare two or three
actual silhouette/massing organizations before detailing every part. CMF variants
of the same solid remain CMF alternatives. Do not impose moodboards or new approval
loops on a user who has already chosen.

`assets/style_vocabulary.json` distinguishes domestic/precise minimalism,
discreet/expressive gamer, precision/robust industrial, pebble/fluid organic and
Art Deco/1950s retro. These are optional vocabularies, not universal style standards.
Custom directions remain valid. `scripts/style_brief.py` selects only the relevant
profile/cards rather than loading the entire library into context.

## Reference cards with honest provenance

`assets/reference_cards.json` reuses the prior researched sources. Open selected
photographs before claiming a visual finding; the supplied cards deliberately have
no reviewed images. For an actual project add image URL/file, source, date,
variant/object, observations and intended transformation. Borrow a principle of
organization; do not silently copy dimensions, mechanisms, materials or logos.

## An identity that spans parts

Define a short family grammar: primary volume hierarchy, transition family,
seam/fastener alignment, opening rhythm and material/finish hierarchy. Link each
rule to actual affected parts and engineering checks. One radius everywhere is not
a grammar: edge scales and function matter. A lid, base and grip should share a
reasoned relationship while retaining service, contact and process requirements.

For each selected change record part/feature, current issue, desired result,
parameter/datum, affected requirement and review evidence. Resolve silhouette and
proportion before decorative details. Retain before/after evidence and record which
criterion improved; no universal beauty score. Desired texture/comfort remains a
hypothesis until made/evaluated physically.

## Family and interaction intent (optional)

When multiple interacting parts are requested, record optional `family_rules`
(shared features, controlled variations) and `interaction_intent` (part → action →
engineering constraint → evidence needed). `make_brief` accepts both as keyword
objects; existing and custom briefs remain valid. These are declarations, not checks.

For drawers: relate front silhouette, handle attachment/section and seam rhythm.
Check travel, finger approach, stop/retention and print orientation against engineering.
A rounded handle is not evidence of comfort. A request for common handles takes
priority over making each style different. Keep shared internals and interfaces when
useful; distinguish styles through allowed massing, transitions and visible joints.

For a console or lamp: coordinate enclosure, grille, service cover and cable exit.
A grille may echo the enclosure rhythm only within engineering limits for openings,
airflow, cable bend, access and retention. These examples define relationships;
they provide no standard dimensions and do not replace engineering checks.

Use the requested scope: only color → labelled CMF study, existing CAD reused;
one selected style → that direction, no mandatory five alternatives. Keep an explicit
user limit on response length. Read only selected reference cards and affected checks.
